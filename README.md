# christopherramos.github.io

Public support and privacy pages for Chris Ramos's apps, published with GitHub Pages at
https://christopherramos.github.io/.

Each app gets its own folder with an `index.md` (support page) and `privacy.md` (privacy policy):

| App | Support | Privacy policy |
|---|---|---|
| HornToad | `/horntoad/` | `/horntoad/privacy` |
| BookRewards | `/bookrewards/` | `/bookrewards/privacy` |

Only put content here that is meant to be public. App source code lives in separate private repos.
